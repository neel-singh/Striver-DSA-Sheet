## Bit Manipulation

**Solved:** In Progress

### Patterns Covered

* Bitwise operators (`&`, `|`, `^`, `~`)
* Left shift (`<<`) and right shift (`>>`, `>>>`)
* Checking, setting, clearing, and toggling bits
* Counting set bits (Brian Kernighan's Algorithm)
* Power of 2 and Power of 4
* Odd/Even checks
* XOR properties and unique element problems
* Bit masking
* Subsets using bit masking
* Divide without multiplication, division, or modulus
* Bit tricks and optimizations

### Notes

* Focus on understanding binary representation and bitwise operations.
* Learn common bit tricks to optimize time and space complexity.
* Practice identifying problems where bit manipulation provides a simpler or faster solution.
* Emphasis on recognizing patterns such as XOR cancellation, bit masking, and shifting.
* Pay special attention to edge cases involving `0`, negative numbers, integer overflow, and signed vs. unsigned shifts.
